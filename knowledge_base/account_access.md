# Account access and password resets

Customers can reset a password from the sign-in page by choosing **Forgot password?**. The reset link is sent to the email address on the account and expires after 30 minutes. If the email does not arrive, check the spam folder and confirm that the address is correct.

For security, support agents cannot see or send a customer's current password. If a customer no longer has access to their account email, the identity verification team must update the email address before a password reset can be sent.
